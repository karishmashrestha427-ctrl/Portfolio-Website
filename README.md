# Karishma Shrestha - Personal Portfolio

## Files
- `index.html` — website content
- `css/style.css` — website design
- `js/script.js` — menu and contact form
- `cv/` — place your CV PDF here
- `img/` — place your profile photo here

## Add your CV
Your uploaded CV is already included as `cv/Karishma-Shrestha-CV.pdf`. The Download CV buttons point to this file.

## Run on GitHub Pages
1. Extract this ZIP file.
2. Create/sign in to your GitHub account.
3. Create a new repository, for example `karishma-portfolio`.
4. Upload all the files and folders from this project (upload the contents, not the ZIP file).
5. In the repository, open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose branch **main** and folder **/(root)**, then press **Save**.
8. Wait a little, then open the website link shown in the Pages section.

The contact form opens the visitor's email app. It does not send or store messages on a server.
